# Capturas reales de Chrome — gestor y ficha

Todas las cuentas y pacientes son ficticios. Resoluciones1366×768,1440×900,1920×1080 y390×844. Capturas revisadas visualmente, además de comprobar geometría, ausencia de wrappers duplicados y controles de guardado visibles.

Los `before` reconstruyen la presentación cliente de5984318 con sus assets originales y HTML equivalente del formulario sobre el backend QA actual. No son una ejecución del backend antiguo. El método está en baseline-capture.json y su script reproducible está versionado. Antes y después utilizan las cohortes ficticias158/166 respectivamente: se compara distribución, no datos ni rendimiento. Se espera el cierre del preloader.
